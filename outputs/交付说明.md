## 4. 评测结论摘要

- 10 道题中 **7 题完全正确、1 题部分正确、2 题错误**（外加语料外拒答题未拒答）；**9/11 题的关键证据被召回**。
- 3 道全景题全部正确：16 家公司「主要会计数据」表全部解析成功，营收前五 = 茅台 1688.38 亿、五粮液 405.29 亿、汾酒 387.18 亿、泸州老窖 257.31 亿、洋河 192.11 亿。
- 典型错误（都写进报告）：
  1. **合并 / 母公司口径混淆**：汾酒省外收入把母公司口径表的 21.8 万元排在合并口径 252.02 亿元之前；
  2. **章节被淹没**：口子窖「可能面对的风险」被审计报告里的同类词挤出 Top-3；
  3. **不会拒答**：抽取式问答缺少「证据不足就说没有」的机制。
- 工程一致性校验：浏览器端分词器与 Python **逐 token 一致**、BM25 排序**逐条一致**、网页检索与离线评测 Top-K **8/8 一致**、浏览器内查询向量与 Python **逐位相同**（余弦 1.000000）。

## 5. 如何复现

```bash
pip install -r requirements.txt
python scripts/download_reports.py     # 下载 48 份报告（约 175MB）
python scripts/extract_text.py         # 解析文字与表格
python scripts/chunk_reports.py        # 切块
python scripts/build_index.py          # BM25 + 向量
python scripts/export_web.py           # 导出网页数据
python scripts/eval_questions.py run   # 跑 10 道题
node scripts/run_system_answers.mjs    # 生成系统回答
python scripts/eval_questions.py build # 合并人工判定
python scripts/build_report.py         # 生成 eval/rag_eval.md
python -m http.server 8000             # 本地预览
```

## 6. 说明

- 仓库不存放 175MB 原始 PDF（可用脚本一键重下），但保存了全部报告的链接、公告日期、页数、表格数与哈希，成果可完全复现。
- 网页首次打开需加载约 8.7MB 索引（BM25 模式即可问答）；点击「启用语义检索」再按需下载约 38MB 模型与运行时。
- 本项目仅用于课程作业与技术演示，不构成投资建议。
